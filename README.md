# Service Model in AWS: IaaS, PaaS, SaaS Visual

Dependency-free teaching site. An animated stack diagram (on-premises, IaaS, PaaS, SaaS) shows which layers you manage and which the vendor manages. Click a model for details, AWS examples and a responsibility table.

## Run
Open `index.html` in a browser. No build step.

## Deploy on GitHub Pages
Push to GitHub, then Settings > Pages > deploy from the `main` branch root.

`assets/reference-diagram.png` is the source diagram the animation recreates.
